# 武器联动与组合图鉴设计

> 更新日期：2026-10-11
> 状态：已确认的设计方向，尚未实现。
> 本文记录后续玩法规划，不代表当前游戏已经具备这些功能。

## 1. 玩法定位

以生存清怪为基础，以发现、搭配和收集大量 combo 为核心乐趣。
玩家在单局中获取随机材料，选择并激活武器联动，通过不同搭配形成不同打法；
跨局通过组合图鉴记录曾经选择过的 combo，形成持续收集的目标。

清怪爽感是组合发挥作用后的回报，组合尝试与图鉴收集是主要的长期动力。
参考《背包乱斗》的组合构筑体验；本次确认范围不包含背包网格、物品摆放或邻接规则。

## 2. 组合材料与联动规则

- 武器、强化、遗物可以作为组合所需材料；遗物属于后续规划内容。
- 选择 combo 时保留原材料，不消耗、不合成替换原武器。
- combo 在原有能力之上增加联动效果。
- 同一材料可以参与多个 combo，支持多个联动共同构成一套打法。
- 第一版以两项材料配方为主，少量三项进阶配方；更多材料的复杂配方留待后续评估。

## 3. 单局获得流程

```text
获取材料 → 满足组合配方 → 升级选项中出现 combo → 玩家选择 → 本局联动生效
```

- 满足配方只使 combo 具备出现资格，不自动激活。
- 玩家仍通过升级选择决定是否获得该 combo。
- 首次选择该 combo 时，同时点亮对应图鉴条目。
- 未选择的 combo 不因材料齐全或出现在选项中而解锁图鉴。

## 4. 组合图鉴

### 4.1 初始状态与解锁

- 所有组合条目初始显示黑色剪影。
- 玩家首次选择对应 combo 后，图标亮起，永久记录为已解锁。
- 图鉴用于记录组合收集进度，不直接授予本局能力。

### 4.2 鼠标悬停

鼠标悬停在图鉴条目上时，**只显示该组合所需材料**，不展示效果。
未解锁与已解锁条目的悬停提示均遵循这一规则。

提示格式示意：

```text
所需材料：材料 A + 材料 B（+材料 C +材料 D）
```

其中材料名称是格式占位符，不代表已确定的配方。
悬停提示不显示箭头后的组合结果、效果说明、伤害数值或触发效果描述。
选择界面的信息展示另行确定，本条规则仅约束图鉴悬停提示。

## 5. 跨局规则

- 图鉴解锁记录永久保存，结束对局或重新启动游戏后仍保留。
- 新一局需要重新获取材料，并重新选择 combo 才能获得对应联动。
- 图鉴已经解锁不意味着后续对局直接赠送材料或自动激活联动。
