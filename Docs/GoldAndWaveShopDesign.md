# 金币与波次间商店

更新日期：2026-10-11。

## 第一版范围

先完成“击杀直接获得金币 → 波次结束进入商店 → 购买治疗或跳过 → 下一波”。
素材商品和限额存款暂不实现，后续独立扩展。

## 基础规则

- 怪物死亡时保留原经验掉落，直接获得 1 金币。
- 不生成金币掉落物，不需要拾取或波末收集；HUD 右上角显示本局金币。
- 商店期间暂停战斗和波次计时，不自动倒计时进入下一波。
- 第一版沿用战场存续规则：存活敌人、经验和投射物在商店期间冻结，继续后恢复。
- 商店仅出售治疗药水：8 金币恢复 4 点生命，每波限购一次。
- 满血、金币不足或本波已购买时不能购买，不扣金币；治疗不超过生命上限。
- 点击“继续下一波”关闭商店并开始下一波，无需购买。
- 金币仅在本局使用。重新开始、返回主菜单后清零。
- 击杀奖励、治疗价格与治疗量可通过 GameManager Inspector 调整；以上是当前验证值。

## 商店界面

- 使用桌面货架式布局，设置三个固定商品栏位；第一版仅左侧出售治疗药水，另外两个栏位预留。
- 药水直接摆在货架上，下方价签显示价格及购买状态；点击药水购买，不再设置独立购买按钮。
- 原棕色货架面与棕黑色底座合并为单块木板，避免两个横杠突兀地叠在商品下方。
- 鼠标悬停药水或通过键盘选中时，显示治疗量、每波限购规则及当前购买状态；离开商品后隐藏提示。
- 已售出药水变暗；满血、金币不足和已售出时无法购买，但仍能悬停查看说明。
- 继续下一波按钮保留；本次只调整界面，素材商品与存款仍待后续实现。

## 后续规划

- 存款不是第一版的功能，不提前确定限制数值。

## 验证记录

2026-10-11 闭环修复：

- 战斗、经验吸收、伤害、刷怪和武器攻击仅在 Playing 状态执行，避免暂停、商店或死亡界面被升级和攻击打断。
- 连续获得多个等级时保留当前升级选项，依次处理待选升级，不重复随机刷新已显示的选项。
- 死亡关闭升级面板并清空待选升级；过期的升级回调不能恢复战斗。
- 重开及返回菜单时立即停用旧敌人、经验、金币、武器与敌方弹幕，回收魔法弹、清除火焰粒子和伤害飘字，避免上一局对象在销毁前继续影响新局。
- HUD 首次启用与重开统一使用 Rebind，避免重复订阅生命、经验和波次事件。
