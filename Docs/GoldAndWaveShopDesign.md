# 金币与波次间商店

更新日期：2026-10-12。当前金币、治疗及像素装备面板式商店已实现，商店布局由 Unity 编辑器维护。

## 第一版范围

先完成“击杀直接获得金币 → 波次结束进入商店 → 购买治疗或跳过 → 下一波”。
素材商品和限额存款暂不实现，后续独立扩展。

## 基础规则

- 怪物死亡时保留原经验掉落，直接获得 1 金币。
- 不生成金币掉落物，不需要拾取或波末收集；HUD 右上角显示本局金币。
- 商店期间暂停战斗和波次计时，不自动倒计时进入下一波。
- 第一版沿用战场存续规则：存活敌人、经验和投射物在商店期间冻结，继续后恢复。
- 商店仅出售治疗药水：8 金币恢复 4 点生命，每波限购一次。
- 满血、金币不足或本波已购买时不能购买，不扣金币；治疗不超过生命上限。
- 点击“继续下一波”关闭商店并开始下一波，无需购买。
- 金币仅在本局使用。重新开始、返回主菜单后清零。
- 击杀奖励、治疗价格与治疗量可通过 GameManager Inspector 调整；以上是当前验证值。

## 商店界面

- 使用像素装备面板式布局，设置三个固定商品卡片；左侧出售治疗药水，另外两个为禁用的预留栏位，隐藏各自药水图标。
- 商店在 SampleScene 的现有 Canvas 下手工搭建，使用 Screen Space - Overlay 与 Constant Pixel Size；商品卡片模板为 `Assets/Prefabs/UI/HealingCard.prefab`。
- 图标、商品名称、价格和购买按钮分开显示；点击购买按钮调用 BuyHealing，不再点击图标购买。
- 鼠标悬停购买按钮或通过键盘选中该按钮时，显示治疗量、每波限购规则及当前购买状态。提示由悬停或选中状态决定；仅悬停图标不会显示详情。
- 已售出药水变暗；满血、金币不足和已售出时无法购买，但仍能悬停查看说明。
- 继续下一波按钮保留；本次只调整界面，素材商品与存款仍待后续实现。

## 编辑器与脚本分工

- Hierarchy、RectTransform、Image、TMP 文字、按钮配色及默认显隐在编辑器配置，退出 Play Mode 后保存场景。
- `WaveShopUI` 挂在 GameManager 所在对象，通过九个 SerializeField 字段引用手工界面；Awake 校验引用、绑定购买和提示事件，不再创建 Canvas、面板或卡片。
- Refresh 更新波次、金币、生命、价格、按钮文字、可购买状态及详情。BuyHealing 的资格校验仍由 GameManager 执行。
- 购买按钮 On Click 留空，由脚本绑定；ContinueButton 的 On Click 在 Inspector 中绑定 GameManager.ContinueFromShop。
- 预留卡片的文字、禁用按钮和隐藏图标作为 Prefab 实例覆盖保留，不向原药水模板 Apply All。
- Kenney Pixel Adventure 边框使用九宫格；药水从 0x72 图集副本 DungeonItemsUI 中手动切片，不修改原战斗图集。

具体层级、字段映射及布局参数见 [商店 UI 编辑器维护指南](UIEditorGuide.md)。
