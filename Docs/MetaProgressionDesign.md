# 局外成长与法师天赋图

更新日期：2026-10-12。首个片区已实现，武器特色与外围片区留待后续扩展。

## 当前规则

- 初始角色为法师，首片区偏向通用伤害、范围、生存能力。
- 节点与连线构成天赋图，允许分叉、路线交汇和小环路。
- 起点免费，相邻节点投入第 1 点即可向外继续，不要求前节点点满。
- 部分节点多级，每级消耗 1 点；没有互斥节点，最终全部可点满。
- 支持免费重置，返还全部已分配点数，保留经验和累计获得点数。
- 主菜单可以查看和分配天赋，战斗中不能打开；修改在下一局开始时生效。
- 死亡、重开、主动返回菜单均按本局表现结算，同一局只能结算一次。

## 局外经验与天赋点

以下是第一版默认值，均可在天赋图配置中调整：

- 有效对局：击杀至少 1 只怪物，或实际战斗至少 15 秒。
- 无效局结算 0 经验，避免反复即时重开获取最低奖励。
- 有效局经验 = 10 + floor(击杀数 / 5) + floor(战斗秒数 / 15) + 完成波数 × 3。
- 战斗时间仅 Playing 状态累计，商店、暂停、升级选择和菜单不计时。
- 完成波数以本局实际进入波末商店的次数计，未打完当前波不算完成。
- 已累计获得 n 点时，下一点费用 = min(250, 10 + 4n + n²)。
- 前五点依次需要 10、15、22、31、42 经验，后期每点最多 250 经验。
- 重置不会降低下一点费用或重复获得奖励。
- 剩余经验跨局积累；当前 33 点全部获得后仍保留经验，注册新片区时可继续换点。
- 正常有效局均有经验进度，不保证每局都能获得一个天赋点。

## 界面

主菜单新增“天赋图”入口、可用点数、经验进度和本次会话上局结算。死亡界面显示天赋经验与新增点数。

天赋图支持拖拽平移、滚轮缩放、回到起点、悬停说明、选中后投入点数、免费重置。路线有独立颜色，已点亮的路径显示金色连线，右侧显示节点状态及当前天赋总加成。

实际 UI 预览：`Screenshots/mage_talent_graph_preview.png`。示例分配仅存在于隔离验证存档。

## 模块与扩展入口

- `TalentGraph.cs`：节点/连接/成长规则定义，连通关系、唯一 ID、效果合法性与可达性验证；`TryAppend` 注册新增片区，失败不部分修改图。
- `TalentEffects.cs`：效果 ID 与处理器注册，节点配置只保存效果 ID 和数值。
- `MetaProgression.cs`：经验换点、加点资格、重置、结算去重和版本化存档，独立于游戏状态与界面。
- `TalentGraphUI.cs`：读取图配置构建节点/连线，显示状态并处理输入；最终加点规则由服务校验。
- `GameManager`：对局开始应用天赋快照，结束时结算；局内升级与局外加成分开，不反复修改基础资产。
- 内置配置：`Assets/Resources/Progression/MageTalentGraph.json`，节点 ID 为 `core.mage.*`，效果 ID 为 `core.*`。

新内容包可以使用独立命名空间定义节点，连到现有节点，然后调用 `MetaProgression.TryRegisterContent`。自定义效果需先注册到 `TalentEffectRegistry`；当前内置处理器覆盖通用属性。追加内容后，界面会按新增节点和连线重建。

本次没有接入外部 mod 文件目录或创意工坊 SDK，也没有实现任意脚本加载。后续沿上述入口加入内容发现、平台上传下载、包版本/依赖校验。命中与击杀触发型武器天赋留到外围片区再接战斗事件。

## 存档

路径：`Application.persistentDataPath/meta_progression_v1.json`。

保存版本、累计经验、剩余经验、累计获得点数、已结算对局 ID 记录、节点稳定 ID 与等级。结算及分配后立即保存，先写临时文件，备份上次正式文件为 `.bak`，再原子替换正式文件。

- 缺失内容的节点 ID 和投入点数保留，不应用效果；重新注册内容后恢复效果。
- 已知节点超过新等级上限时降到上限，差额返还可用点数。
- 配置改变导致已知节点与起点断开时返还其点数。
- 无法读取或不支持的版本保留原文件，不以空进度覆盖，界面显示存储提示。
- 保存失败保留本次会话的内存进度并提示，后续保存与退出时重试。
